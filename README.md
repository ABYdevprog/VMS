# VMS — Otonom Yazılım Ajansı & Türkiye KOBİ Ürün Stüdyosu

7 uzman yapay zeka ajanı (**Atlas, Pusula, Mimar, Demir, Yankı, Avcı, Bilge**), günlük 4 vardiya otomasyonu, **Kaizen versiyonlu Playbook öz-gelişim motoru**, **Çift Yönlü WhatsApp CEO Köprüsü** ve Türkiye KOBİ'leri için 30 saniyede kişiselleştirilen **KOBİ Asistan Pro Canlı Demo Fabrikası**.

## Hızlı Başlangıç

```bash
npm install
npm run db:seed
npm run dev
```

- **KOBİ Ürün Vitrini:** `http://localhost:3000`
- **CEO Kontrol Kokpiti:** `http://localhost:3000/cockpit`
- **Örnek Kişiselleştirilmiş Canlı Demo:** `http://localhost:3000/demo/ozel-dentmoda-kadikoy`

## Antigravity & CLI Otomasyon Komutları

```bash
npm run vms -- status
npm run vms -- shift:catchup
npm run vms -- shift:run all
npm run vms -- directive "Yarın Kadıköy diş kliniklerine odaklanın"
npm run vms -- approve:all
```
